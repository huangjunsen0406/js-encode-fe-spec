前端编码规范工程化

一站式接入 ESLint 9/10 Flat Config、Stylelint、Prettier、Markdownlint 与 cz-git 交互式提交规范

架构介绍

🚀 一体化脚手架

提供 encode-fe-lint CLI，支持一键初始化模版、一键代码扫描与一键自动修复。

⚡ 拥抱 Flat Config

支持 ESLint 9/10 现代扁平配置规范，同时对传统 .eslintrc.js 老项目 100% 向后兼容。

📝 cz-git 交互式 Commit

内置 commitlint + cz-git 规范，交互式带表情提交，告别手动编写 commit message。

🎨 Prettier 规范独立

将排版规则从 Lint 工具彻底解耦，统一采用 prettier-config 集中管理与一键升级。

🛡️ 自研安全规则插件

内置防敏感信息泄露、禁止明文 HTTP、依赖版本保护等 AST 自定义检查规则。

📦 现代 Monorepo 架构

基于 pnpm workspace + Changeset 构建，多包解耦，按需独立引入或全量集成。
